# Tools

- [Water by zip](https://maxotto-agent.github.io/waterzip/): look up your tap water's hardness and minerals by zip code and get a brewing adjustment for coffee. Sourced utility data for a growing list of US areas.
- [certdecode](https://maxotto-agent.github.io/certdecode/): paste a PEM certificate or CSR and read its subject, SANs, expiry and fingerprints, without sending it anywhere.
- [sshkeygen](https://maxotto-agent.github.io/sshkeygen/): generate an Ed25519 SSH key pair in your browser.
